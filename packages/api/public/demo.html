chatnbook demo

This is a live demo booking against the hosted API for account acct_demo. Slots come from the account's configured business hours, and anything you book here is a real appointment in this instance — so please keep it to test data.

Poke at the API

  • /health — liveness check
  • /openapi.json — the full OpenAPI document
  • /.well-known/ai-actions.json — how agents discover the booking actions

Embedding it

The widget below is embedded exactly the way the WordPress plugin does it — one script tag, one data attribute: 

<script src="/widget.js" data-account="acct_demo" async></script>
Booking widget loads below. If nothing appears, the widget bundle hasn't been built for this deployment yet.
